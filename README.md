# AI Engineer Technical Assessment

Welcome to your technical assessment for the **AI Engineer** position. This repository contains the tasks designed to evaluate your practical skills and problem-solving abilities.

This assessment is structured to mirror a real-world development workflow. You will complete each task in a separate branch and submit it as an individual Pull Request.

---

### 🗓️ Assessment Duration
You will have **1 week(s)** to complete and submit all tasks from the moment you receive access.

---

### 🚀 Getting Started
1.  **Clone this Repository:** Clone this repository directly to your local machine. This will be your working environment for all submissions.
2.  **Explore the Tasks:** Navigate to the `/submissions` directory. You will find a folder for each task (e.g., `task-1`, `task-2`). Each folder contains an `Instruction.md` file that details the specific requirements for that task.

---

### 📝 How to Submit Each Task
You will repeat this process for **every task** in the assessment.

1.  **Create a Task-Specific Branch:** From the `main` branch, create a new branch with a descriptive name for the task you are starting (e.g., `feature/task-1-solution`).
2.  **Complete the Task:** Write all your code and solutions for the task within its dedicated folder (e.g., `/submissions/task-1/`). Commit your changes to your task branch frequently.
3.  **Create a Pull Request (PR):** When you have completed a task, create a Pull Request from your task-specific branch to the `submissions` branch of this repository.
    -   **Important:** Ensure your Pull Request title clearly indicates which task it is for (e.g., "Submission for Task 1: [Your Approach]").
4.  **Submit Your PR Link:** Once your PR is created, copy its URL and **submit it on the corresponding task page on your student dashboard.**

---

### ⚠️ Important Rules
-   **One Branch, One PR Per Task:** Each task must be completed in its own branch.
-   **Do NOT push directly to the `main` branch**.
-   **Finalize Before Submitting:** Ensure you are satisfied with your solution before submitting.

---

### 💡 Evaluation Criteria
-   **Code Quality (25%):** Readability, maintainability, best practices.
-   **Testing (20%):** Presence and effectiveness of tests.
-   **Performance (20%):** Efficiency and resource utilization.
-   **Documentation (20%):** Clarity of comments and docs.
-   **Accessibility (15%):** Usability and robustness of your solution.
